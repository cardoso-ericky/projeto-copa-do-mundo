# projeto-copa-do-mundo
Projeto realizado durante as aulas de Back-End

- No botão Code, clique em "Download ZIP"
- No computador, extraia o projeto do arquivo .zip baixado
- Abra a pasta do projeto extraída no VSCode (abra o programa, clique em abrir pasta, escolha a pasta extraída)
- Na pasta do projeto, no VSCode, abra o terminal e digite o seguinte comando:<br/><code><i> npm init -y </i></code>
- Isso criará um arquivo, package.json, no seu projeto
- Abra este arquivo, coloque seu nome no atributo "author" e altere (ou adicione, caso não tenha) o atributo "type" para "type": "module" (lembre de adicionar uma vírgula ao final da linha, caso ela não seja a última antes do fechamento das chaves {} )
- Voltando para o terminal, digite o comando: <br/><code><i> npm install express </i></code>
- Rode a aplicação usando: <br/><code><i> node server.js </i></code>
- Abra o navegador de sua preferência e, na barra de endereços, digite <br/><code><i> http://localhost:3019 </i></code>
- Caso algum erro ocorra em alguma etapa do processo, você pode pedir ajuda ao professor
- Lembre de adicionar a funcionalidade para acessar os Grupos do mesmo modo que as seleções
